# 独自実装
* エディタ上でパラメータUIの自動生成とリアルタイム調整ができる
  * （工夫した点）C++側で変数を登録するだけでインスペクターUIが自動生成されるリフレクション基盤を構築し、プランナーでも安全に調整と保存ができるようにした。
* 1万個以上の瓦礫を処理落ちさせずに物理演算で動かせる（大規模な破壊表現ができる）
  * （工夫した点）世代付きHandleによる安全なメモリ管理と、Compute Shaderへの演算オフロードを組み合わせることで、CPU負荷を極小化しフレームレートを維持した。
* 重いモデルやテクスチャをロードしても、ゲームの進行を止めることなく（カクつかずに）裏で読み込める
  * （工夫した点）自前のスレッドプールを用いた非同期ローダーを実装し、メインスレッドをブロックせずにバックグラウンドでアセットをロードできるようにした。
* 「AIMagicBrush」：テキストや参考画像を指定するだけで、AIが自動でHLSLシェーダーコードを生成・出力する
  * （工夫した点）非同期でPythonのAIサーバーと連携し、コンパイルエラーが発生してもAI自身がログを読んで自動修復する自律的なシェーダー生成システムを構築した。
* AIが生成したシェーダーコードが要件を満たしていない場合、AIにエラーや改善点を評価させ、コードを自動修正させることができる
  * （工夫した点）AI自身にフィードバックループを構築させることで、専門知識がなくてもシェーダーコードのベースを素早く構築できるようにした。
* Releaseビルドのゲーム画面を一切塞ぐことなく、別モニタでリアルタイムにFPSやCPU/GPU処理時間、マルチスレッド稼働状況をプロファイリングできる
  * （工夫した点）UDP通信を採用して非同期にJSONデータを送信し、別プロセス（C# WPFアプリ）で受信・グラフ化することで、ゲーム本編へのオーバーヘッドを最小化しつつ本番環境の正確な負荷計測を可能にした。
