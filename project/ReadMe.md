# CG4 評価課題 提出資料

## 実装した加点要素について

本プロジェクトでは、スライドで提示された加点要素のうち、以下の項目を実装しております。

### 1. Skinningモデルの表示 (20点)
- `SkinnedMeshRendererComponent` を実装し、`.gltf` や `.glb` フォーマットのアニメーション付きモデルを正しく描画できるように対応しています。
- シーン上には、プレイヤーカーソルの入力で動かせる歩行モデルや、`BrainStem.glb` など複数のスキニングモデルが配置されています。

### 2. コンピュートシェーダーによるスキニング (10点)
- `Skinning.CS.hlsl` を用い、CPU ではなく GPU (Compute Shader) 上で並列にスキニング（ボーンによる頂点変形）を行っています。
- これにより、CPU の演算負荷を解放し、計算後の頂点バッファを直接描画パイプラインへ効率的に送るアーキテクチャを採用しています。

### 3. MultiMesh & MultiMaterial対応 (5点)
- **MultiMesh**: SkinCluster を拡張し、複数メッシュを持つGLTFモデルがそれぞれ正しいボーンウェイトと頂点オフセットを参照できるように対応しました（頂点爆発バグを解決）。
- **MultiMaterial**: 各部位（マテリアルスロット）ごとに色や質感（Metallic/Roughness）を独立して上書き（Override）できる機能を追加しました。エディタの Inspector から動的に編集でき、シーンへのシリアライズにも対応しています。

### 4. Animation補間 (5点)
- `AnimatorComponent` と `AnimationManager` において、フレーム間の姿勢補間ロジックを実装しています。
- また、アニメーションの切り替え時（待機 ↔ 歩行 ↔ しゃがみ等）に、`fadeDuration`（フェード秒数）を用いたアニメーションブレンド（クロスフェード）が行われ、モーションが滑らかに遷移します。

### 5. 骨のデバッグ表示 (10点)
- `SkeletonDebugRendererComponent` を実装し、ボーン階層を X-Ray（最前面）表示する機能を備えています。
- 関節部分はスカイブルーの球 (Sphere) で、骨の部分はピンクの八面体 (Octahedron) でそれぞれ描画され、アニメーションの動きをエディタ上で視覚的にデバッグ可能です。

### 6. その他 (10点)
※SkinningやSkeleton、Animationに関連する独自の拡張・対応
- **非同期ロードの安定化とアニメーション不具合修正**: アニメーション付きGLTFモデルを非同期ロードする際の Use-After-Free バグや、一部のモデルで時間が NaN（ゼロ除算）になる不具合を修正し、安全かつ確実にアニメーションを再生できる基盤を整備しました。
- **スケルタルモデルのRaycast (OBB) 対応**: Rootノードにスケール値を持つ特殊なGLTFモデル（BrainStemなど）において、スケルトン構造のバインドポーズ変換行列を計算し、モデルの見た目と当たり判定（マウスでのクリック判定用OBB）が完璧に一致するように修正しました。
