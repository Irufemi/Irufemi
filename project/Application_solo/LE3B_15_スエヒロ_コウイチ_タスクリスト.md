# タスクリスト (プロト完成までのバックログ)

※最大4時間（1ユニット）ルールの適用
※バッファルール：見積もりの2倍の時間が経過した時点で、実装アプローチを見直すかデスコープする。

## 【Must-Have】優先度：高（コア・ゲームプレイ：次週予定候補）
> アジャイルメンター評価：最も優先すべき「操作キャラクターの基本的な挙動」と「ゲームシステムの根幹」のタスク群です。

- **T-1: 3Dスプライン上のオフセット移動の完全実装 (計3h)**
  - [ ] T-1.1: XInput/DirectInputによるゲームパッド（左スティック）とWASDキーの正規化された移動入力ベクトル取得 (1h)
    - **DoD (完了定義):** 入力値が-1.0〜1.0の範囲でログ出力され、デッドゾーン処理が正しく機能していること。
  - [ ] T-1.2: スプライン曲線の現在地点における接線ベクトルから、従法線(Binormal)・法線(Normal)を算出し、自機のローカルXY平面を構築 (1h)
    - **DoD (完了定義):** ルートがカーブ・宙返りしても、自機の上下左右軸がルートに対して常に正しく維持されること。
  - [ ] T-1.3: 取得した入力ベクトルをローカルXY平面に適用し、壁抜け防止の移動制限（クランプ）処理を実装 (1h)
    - **DoD (完了定義):** プレイ動画で、カーブするルート上を進みながら、画面端を飛び出さずに自機を自由に動かせること。

- **T-4: メモリ管理（Object Pool）の堅牢化とメモリ枯渇防止 (計1.5h)**
  - [x] T-4.1: ガレキ・ザコ敵の Object Pool 適用 (完了済)
  - [ ] T-4.2: ボスの弾幕用データ構造体の定義と、初期化時のObjectPool事前割り当て処理の実装 (1h)
    - **DoD (完了定義):** ボス戦開始時にメモリ確保のスパイク（処理落ち）が発生しないこと。
  - [ ] T-4.3: 投擲して外れたガレキが一定距離または一定時間（LifeTime）経過後にプールへ確実に返却される処理の実装 (0.5h)
    - **DoD (完了定義):** ガレキを無限に投げ続けても、タスクマネージャー上でメモリ使用量が増加し続けない（安定している）ことが動画で確認できること。
