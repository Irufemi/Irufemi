## 【Must-Have】優先度：高（コア・ゲームプレイ：次週予定候補）
> アジャイルメンター評価：最も優先すべき「操作キャラクターの基本的な挙動」と「ゲームシステムの根幹」のタスク群です。

- **T-1: 3Dスプライン上のオフセット移動の完全実装 (計3h) [完了]**
  - [x] T-1.1: XInput/DirectInputによるゲームパッド（左スティック）とWASDキーの移動入力ベクトル取得 (1h)
    - **DoD (完了定義):** 入力値が正しく取得され、長押しによるシームレスな移動が行えること。
  - [x] T-1.2: PlayerCart（親）とPlayer（子）の階層化による、レール移動とローカルオフセット移動の分離 (1h)
    - **DoD (完了定義):** ルート進行と回避移動の座標計算が分離され、シンプルかつ安全に移動処理が行えること。
  - [x] T-1.3: 慣性・姿勢制御（ロール）・浮遊感アニメーションの実装および壁抜け防止クランプ (1h)
    - **DoD (完了定義):** 加速度による急発進・摩擦による急制動が効き、移動方向に機体が傾き、常に浮遊している「グラビティデイズ風」の操作感が実現できていること。

- **T-4: メモリ管理（Object Pool）の堅牢化とバリエーション対応 (計2.5h)**
  - [x] T-4.1: ガレキ・ザコ敵の Object Pool 適用 (完了済)
  - [ ] T-4.2: ボスの弾幕用データ構造体の定義と、初期化時のObjectPool事前割り当て処理の実装 (1h)
    - **DoD (完了定義):** ボス戦開始時にメモリ確保のスパイク（処理落ち）が発生しないこと。
  - [ ] T-4.3: 投擲して外れたガレキの回収処理（限界距離でのデスポーン ＆ 建造物OBBへの衝突破砕）の実装 (1.0h)
    - **進捗:** 限界距離到達時の `Pending Kill` (遅延プール返却) 処理は実装完了。残りは建造物衝突時の破砕演出。
  - [ ] T-4.4: 複数種類のガレキプレハブ（JSON）読み込みと、種類別のObject Pool事前生成（Prefab-Based Pooling）の実装 (1.0h)
    - **DoD (完了定義):** エディタ上で指定された複数種類のガレキがランダムに引き寄せられ、それぞれのモデルに応じた正しいコライダー判定を持っていること。
  - [ ] T-4.5: `EnvironmentManagerComponent` の作成と `GameScene` への組み込み (0.5h)
    - **DoD (完了定義):** テスト用建造物などの環境オブジェクトがシーン直置きではなくマネージャー経由で配置され、今後のデータ駆動化（JSON読み込み）の土台が整っていること。
